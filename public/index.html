📖 คู่มือการใช้งานระบบ IT Asset Management Hub (สำหรับทุกบทบาท)

ขั้นตอนที่ 1 เข้าสู่ระบบยืนยันตัวตนด้วยบัญชี Lark (1-Click SSO)

เมื่อเปิดเข้ามาที่หน้าแรก ให้กดปุ่ม [🚀 เข้าสู่ระบบด้วย Lark (Login with Lark)] เพื่อเข้าใช้งานอย่างปลอดภัย ข้อมูลของคุณจะถูกดึงตรงจาก Lark OpenID โดยไม่มีการสับสนชื่อหรือปะปนกับเพื่อนร่วมงาน

ขั้นตอนที่ 2 ตรวจสอบการ์ดอุปกรณ์ประจำตัวคุณ

ระบบจะแสดงการ์ดอุปกรณ์คอมพิวเตอร์ จอมอนิเตอร์ และอุปกรณ์เสริมที่บันทึกไว้ภายใต้ชื่อของคุณ ตรวจสอบเลขทรัพย์สิน (Asset Tag) บนสติกเกอร์ และเลข Serial Number (S/N) ใต้เครื่อง

ขั้นตอนที่ 3 กดยืนยันข้อมูล หรือ แจ้งข้อมูลซ้ำ / ขอติดป้ายใหม่

• หากข้อมูลถูกต้อง: กดปุ่มสีเขียว [✅ ข้อมูลถูกต้อง] บนแต่ละการ์ด หรือกด [✅ ยืนยันอุปกรณ์ทั้งหมดของฉัน]
• หากมีรายการซ้ำ หรือเครื่องส่งต่อให้คนอื่นแล้ว: กดยืนยันเครื่องจริง 1 เครื่อง จากนั้นกดปุ่ม [✏️ แก้ไข/ย้าย] บนเครื่องที่ซ้ำ แล้วเลือก [🗑️ แจ้งเป็นข้อมูลซ้ำ] หรือ [🏷️ ป้ายสติกเกอร์หลุดหาย] เพื่อส่งเรื่องให้ IT ตรวจสอบทันที

1 ระบบล็อกชื่อผู้ถือครองเป็นชื่อคุณอัตโนมัติ

เมื่อคุณล็อกอินผ่าน Lark SSO ระบบจะดึงชื่อบัญชีและสังกัดบริษัท (XPO หรือ EDDU) ของคุณเป็นผู้ถือครองเครื่องใหม่ให้อัตโนมัติ ป้องกันการกรอกชื่อผิด

2 กรอกเลขทรัพย์สิน & ระบบตรวจจับซ้ำ Real-time

พิมพ์เลขทรัพย์สิน (เช่น COM-00123) และ Serial Number โดยระบบมี Real-time Duplicate Detection หากมีใครเคยลงทะเบียนเลขนี้ไว้แล้ว ระบบจะขึ้นกล่องเตือนสีส้มทันที หรือหากไม่มีสติกเกอร์ ให้ติ๊กเลือก "ไม่ทราบเลขทรัพย์สิน (รอ IT ติดป้าย)"

3 กดบันทึกเพื่อขึ้นทะเบียน

กดปุ่ม [🚀 บันทึกลงทะเบียน & ยืนยันเครื่องเข้าสู่ระบบ] ข้อมูลจะถูกบันทึกลง Lark Base Master ทันที และระบบจะพาคุณกลับมาที่แท็บ 1 เพื่อแสดงการ์ดเครื่องใหม่ที่คุณเพิ่งลงทะเบียน

1 เลือกดูคลังอุปกรณ์ว่างตามหมวดหมู่

เลือกหมวดหมู่ เช่น โน้ตบุ๊กสำรอง, จอมอนิเตอร์, สายชาร์จ, หรือหัวแปลง จากนั้นกดปุ่ม [⚡ ขอยืมอุปกรณ์นี้]

2 เลือกระยะเวลายืมด่วน (1 วัน / 3 วัน / 7 วัน)

กดปุ่มระยะเวลายืมด่วนเพื่อคำนวณวันส่งคืนอัตโนมัติ ระบุวัตถุประสงค์การยืม แล้วกดปุ่ม [📤 ยื่นคำขอยืมอุปกรณ์ชั่วคราว]

3 การส่งคืนอุปกรณ์เข้าคลัง (1-Click Return)

เมื่อนำอุปกรณ์มาคืนที่โต๊ะเจ้าหน้าที่ ให้เปิดแท็บ "รายการที่กำลังยืมอยู่" แล้วกดปุ่มสีเขียว [📥 ส่งคืนอุปกรณ์] เพื่ออัปเดตสถานะเป็นพร้อมใช้งานในสต็อกทันที

IT Admin 1 การเข้าสู่ระบบ IT Admin Dashboard

กดปุ่ม [🔑 สำหรับเจ้าหน้าที่ IT Admin & HR] ที่หน้าแรก หรือเลือกแท็บ 4 แล้วกรอกรหัสผ่านแอดมิน: itadmin2026 เพื่อเปิดแดชบอร์ดบริหารจัดการ

IT Admin 2 ตรวจสอบความคืบหน้าแคมเปญ 7-Day Freeze

ดูกราฟสถิติภาพรวมแยกตามสังกัด XPO และ EDDU, ตรวจสอบรายชื่อพนักงานที่ยังไม่ยืนยัน (Pending List) และรายการที่ป้ายสติกเกอร์สูญหาย (Missing Tag Requests) เพื่อจัดคิวพิมพ์ป้ายบาร์โค้ดใหม่

IT Admin 3 ระบบล้างข้อมูลซ้ำอัจฉริยะ (Smart Duplicate Cleaner)

ระบบจะตรวจจับ Serial Number ที่ซ้ำกันและเคสที่พนักงานกดแจ้งซ้ำ IT สามารถกดปุ่ม [⚡ ล้างรายการซ้ำที่เข้าเงื่อนไขทั้งหมดอัตโนมัติ (Safe Auto-Clean)] เพื่อลบ Record ที่ซ้ำออกอย่างปลอดภัย โดยมีประวัติบันทึกใน Audit Logs เสมอ

IT Admin 4 การดึงเครื่องคนลาออกเข้าคลังกลาง (Resigned Auto-Reclaim)

ในหัวข้อ "พนักงานที่ลาออก / Closed Account" IT สามารถกดปุ่ม [📥 ดึงอุปกรณ์ทั้งหมดกลับเข้าคลังกลาง (Reclaim to Stock)] ระบบจะปลดชื่อผู้ถือครองเดิม และเปลี่ยนสถานะเครื่องเป็น Available in Stock ทันที

IT Admin 5 ศูนย์ควบคุม Lark Bot Notification & Batch Scheduler

สั่งรันบอทยิงการ์ดแจ้งเตือนแบบ 1-on-1 เข้าแชท Lark ของพนักงานที่ยังไม่ได้ยืนยันตัวตน หรือทดสอบส่งการ์ดหาพนักงานเฉพาะบุคคลเพื่อตรวจเช็ค UX ได้ทันที

Admin ธุรการ 1 บริหารจัดการคลังอุปกรณ์กลาง (Central IT Stock)

เข้าใช้งานแท็บ 3 เพื่อตรวจสอบจำนวนอุปกรณ์พร้อมใช้งาน (Available), อุปกรณ์ที่อยู่ระหว่างยืม (On Loan) และตรวจรับอุปกรณ์ที่พนักงานนำมาคืน

Admin ธุรการ 2 การรับมอบเครื่องกายภาพจากพนักงานลาออก (Step 2 ในแท็บ 5)

เมื่อฝ่ายบุคคล (HR) ส่งตั๋วพนักงานลาออกเข้ามา ในวันสุดท้ายของการทำงาน พนักงานจะนำเครื่องและอุปกรณ์เสริมมาส่งมอบ ให้ Admin ตรวจนับอุปกรณ์ให้ครบตามรายการในใบงาน แล้วกดปุ่ม [📦 Admin รับเครื่องจริงแล้ว ➔ ส่งต่อ IT ตรวจสภาพ]

Admin ธุรการ 3 การจัดเตรียมชุด Onboarding Kit ต้อนรับพนักงานใหม่ (Step 4 ในแท็บ 5)

เมื่อ IT ทำการ Reimage และตรวจเช็คสุขภาพเครื่องเสร็จ Admin นำเครื่องมาจัดใส่กล่องชุด Kit ร่วมกับบัตรผ่านอาคาร คีย์บอร์ด และเมาส์ จากนั้นกดปุ่ม [✅ Admin จัดชุด Kit เรียบร้อย ➔ พร้อมเริ่มงาน]

HR ฝ่ายบุคคล 1 การเข้าสู่ระบบส่งต่องาน 3 ฝ่าย (Lifecycle Hub)

เลือกแท็บ 5. ส่งต่องาน 3 ฝ่าย (HR/Admin/IT Hub) จากนั้นกรอกรหัสผ่านฝ่ายบุคคล: lifecycle2026 เพื่อเปิดหน้าจัดการการเข้า-ออกของพนักงาน

HR ฝ่ายบุคคล 2 การเปิดตั๋วพนักงานลาออก (Offboarding Request)

1. กดปุ่มสีแดง [➕ แจ้งพนักงานลาออก (Offboarding)]
2. เลือกชื่อพนักงานที่กำลังจะลาออก ➔ ระบบจะดึงรายการคอมพิวเตอร์และอุปกรณ์ทั้งหมดที่พนักงานคนนั้นถือครองอยู่มาลงในตารางให้ทันที
3. ระบุวันทำงานวันสุดท้าย (Last Working Day) และหมายเหตุ
4. กดปุ่ม [🚀 ส่งเรื่องให้ Admin ธุรการรอดักรับของ]

HR ฝ่ายบุคคล 3 การเปิดตั๋วพนักงานใหม่ (Onboarding Request)

1. กดปุ่มสีเขียว [➕ แจ้งพนักงานเริ่มงานใหม่ (Onboarding)]
2. กรอกชื่อพนักงานใหม่, เลือกสังกัดบริษัท (XPO หรือ EDDU), และเลือกแพ็กเกจอุปกรณ์ (เช่น Standard Kit: โน้ตบุ๊ก + จอ + เมาส์ + บัตร)
3. ระบุวันเริ่มงาน (Start Date)
4. กดปุ่ม [🚀 ส่งเรื่องให้ Admin จัดเตรียมของ] เพื่อให้ทีมงานจัดเตรียมเครื่องล่วงหน้าก่อนเริ่มงานอย่างน้อย 3 วัน

HR ฝ่ายบุคคล 4 การติดตามสถานะความคืบหน้า 3 ฝ่ายแบบ Real-time

HR สามารถดูสถานะของตั๋วทุกใบได้แบบ Real-time ว่าขณะนี้ของอยู่ที่ใคร (Admin กำลังดักรับของ ➔ IT กำลัง Reimage เครื่อง ➔ Admin เก็บเข้าตู้สต็อก) ป้องกันปัญหาเครื่องสูญหายหรือตามคืนไม่ได้ 100%

✏️ แก้ไขข้อมูล / ยืนยันอุปกรณ์

❌ ไม่ได้ถือครองเครื่องนี้แล้ว หรือ รายการข้อมูลซ้ำ?

หากเครื่องนี้ถูกส่งคืน โอนย้าย หรือเป็นรายการข้อมูลซ้ำที่ไม่มีเครื่องจริง ให้เลือกแจ้งด้านล่าง:

📥 ส่งคืนอุปกรณ์ชั่วคราวเข้าคลัง

🚪 HR แจ้งพนักงานลาออก (Offboarding Task)

📦 รายการอุปกรณ์ที่ผูกในระบบ (Auto-Checklist):
พิมพ์ชื่อพนักงานด้านบนเพื่อดึงรายการของอัตโนมัติ

✨ HR แจ้งพนักงานเข้าใหม่ (Onboarding Pack)

📋 ชุดอุปกรณ์ที่จะจัดเตรียม (Onboarding Kit):
- ThinkPad / MacBook 1 เครื่อง
- จอมอนิเตอร์ 1 จอ
- Keyboard + Mouse 1 ชุด
- บัตรเข้าออกอาคาร

✏️ แก้ไขข้อมูล / ย้ายสถานะงาน (Edit Task)
